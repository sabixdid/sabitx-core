# SABITX visual direction

The approved direction is minimal and artistic, built around black, orange and white.

- Black (#090909) is the foundation. Slightly lighter neutral surfaces define the tools.
- Orange (#ff5a1f, with accessible lighter variants for small text) marks the identity and primary actions.
- White is for headings and essential information. Secondary text must remain readable.
- Use generous space, precise typography, a restrained geometric X and clear hierarchy. Use restrained perspective and parallax for an immersive focal object. Keep reading surfaces steady and include a motion pause control. Avoid blue, purple, multicolour glows and content hidden behind animation.
- Keep the identity original. Apple is a reference for restraint and finish, not a template to reproduce.
- Every prominent action leads to a working destination. Planning opens planning; coding opens coding. Do not advertise placeholder modules as active tools.
- Public status describes the response actually received. It does not certify end-to-end execution or imply that a visitor is authenticated.
- Preserve access keys, scoped files, approval gates, existing APIs, and saved work. Visual changes must not weaken those controls.
- Check the production build, desktop and narrow mobile layouts, keyboard focus, reduced motion, and entry points into the existing tools.

SABIT INC shares this palette and typographic restraint on Squarespace. Its public business content remains native to that site; SABITX remains the systems workspace.
